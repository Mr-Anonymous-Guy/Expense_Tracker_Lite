# API Documentation

OpenAPI contract is available at:

```txt
GET /api/openapi.json
```

Main resource groups:

- Auth: register, login
- Expenses: CRUD spending data
- Budgets: monthly and category planning
- Goals: target-based savings planning
- Investments: holdings and SIP tracking
- Analytics: dashboard summary and health score
- AI: insights and local copilot chat
- Reports: weekly and monthly summaries
